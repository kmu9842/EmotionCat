# 입력 데이터와 오프라인 동작

감정 인식은 기본적으로 꺼져 있습니다. 기존 설정을 처음 마이그레이션할 때도 꺼지며, 설정에서 사용자가 켭니다. 발 애니메이션은 계속 사용할 수 있습니다.

입력은 전역 키 이벤트에서만 얻습니다. 비밀번호 필드 판별, 편집 컨트롤 내용 조회, 클립보드 조회를 하지 않습니다. macOS에서는 입력 모니터링 권한만 요청하며, 손쉬운 사용 권한은 요청하지 않습니다.

## 1초 수명

- 첫 문자로 시작한 수집 구간은 0.5초 뒤 분석에 전달합니다. Enter는 현재 구간을 일찍 전달합니다.
- 해당 구간의 원래 수집 시작 시점부터 1초가 폐기 기한입니다. 새 문자나 대기열 이동으로 기한을 연장하지 않습니다.
- 수집 버퍼는 전달 직후 지웁니다. 독립 타이머도 원래 기한에 버퍼를 지우므로 다음 키 입력이 없어도 폐기됩니다.
- 대기열은 지울 수 있는 문자 버퍼를 소유합니다. 기한이 지난 입력은 모델 준비·UI 처리가 늦어져도 다시 분석하지 않습니다.
- 토큰화 후에는 원문 참조를 유지하지 않습니다. 추론은 같은 기한에 취소를 요청하며, 늦게 도착한 결과는 사용하지 않습니다. 네이티브 추론이 반환하면 앱이 소유하는 토큰 배열·텐서 버퍼도 덮어쓰고 해제합니다.
- 일시정지, 종료, 절전·세션 전환 시 대기 입력을 폐기합니다. 원문을 보여주는 진단 화면은 없습니다. 수동 분류 입력란도 제출 즉시 비웁니다.

이 정책은 앱이 소유하는 버퍼와 참조의 수명을 제한합니다. 일반적인 OS 스케줄링은 실시간 보장이 아니며, ONNX Runtime의 실행 취소도 협력적입니다. 네이티브 코드가 사용 중인 메모리를 강제로 해제하지 않습니다. .NET/Swift의 임시 문자열 복사본, 런타임·GPU 내부 메모리, OS 페이지 파일·덤프까지 정확히 1초에 복원 불가능하게 지운다는 보장은 아닙니다.

## 네트워크와 저장

앱은 외부 API·로컬 서버·업데이트 서버에 연결하지 않습니다. 모델과 런타임은 배포본에 포함하며, ONNX Runtime 텔레메트리는 환경 생성 직후 비활성화합니다. Windows의 선택적 추론 프로파일 파일 기능도 제거했습니다.

이미지·모델·설정은 로컬 파일만 읽습니다. 네트워크 공유·네트워크 드라이브·파일시스템 링크 경로를 거부합니다. Windows 네이티브 DLL 검색 범위는 앱 디렉터리와 System32로 제한합니다. 앱이 OS의 방화벽이나 보안 제품 설정을 변경하지는 않습니다.

명시적인 저장 대상은 설정과 가져온 이미지입니다. 타자 원문, 추론 요청 본문, 토큰 기록은 저장하지 않습니다. 개발 의존성 다운로드는 빌드 단계의 인터넷 작업이며 앱 실행 경로에는 포함되지 않습니다.

## 서명과 탐지

릴리스는 코드 서명 인증서나 유료 서명 계정 없이 빌드·패키징합니다. Windows 앱은 공인 코드 서명을 포함하지 않습니다. macOS는 인증서나 네트워크 연결 없이 로컬 ad-hoc 서명을 적용하며, Developer ID 서명과 Apple 공증은 사용하지 않습니다.

이 보안 수정이 Defender·EDR의 행위 판정이나 SmartScreen의 평판 판정을 통과한다고 보장하지는 않습니다. 백신 예외 추가, 실시간 보호 해제, Gatekeeper 격리 속성 제거를 배포 절차에 사용하지 않습니다.
